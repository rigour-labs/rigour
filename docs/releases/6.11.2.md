# Rigour 6.11.2

The import check no longer blocks Rust crates and Go modules that their own manifests declare.

## Fixed

- **The import check no longer blocks Rust crates and Go modules that their own manifests declare; when no
  manifest is found, an unresolved import is a note, not a block.** A Rust file is checked against its own crate's
  Cargo.toml (every dependency section, including target-specific, dev and build ones) and its workspace, wherever
  they sit in the repository. A module or item the file declares (`mod log;`, then `use log::…`) is not a crate. A
  Go import of a module that go.mod requires is never read as a missing folder, even under the module's own path.
  On DriftBench's 325 public heads, this removes all 7 heads that 6.10.0 blocked on approved code, and changes
  nothing else.
