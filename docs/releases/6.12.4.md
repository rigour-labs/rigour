# Rigour 6.12.4

Write-only-property blocks only when it can show the value never leaves the program.

## Fixed

- **Write-only-property blocks only when the value is shown never to leave.** A value stored in a container
  (`map.set`, `push`, `add`, an index assignment) or returned from an exported function nothing in the program calls
  may be read and sent on where the analysis cannot follow, so its unread fields are hints that name where it may
  leave, not blocks. A value that is never stored, sent or returned to such a function still blocks.
