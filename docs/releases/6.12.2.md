# Rigour 6.12.2

Review bots no longer make lessons on their own, and three checks stop reporting problems that are not there: a field
the program does send or read, a test that asserts through a helper, and a check that only found what the code
already had.

## Fixed

- **A lesson is never verified or served on review bots' points alone.** Two review bots raising the same point no
  longer make a lesson, and `gates.deep.review_lessons: all` no longer serves a candidate only bots raised. A point
  from a bot still counts once a person's point is on the same lesson. Lessons an earlier version promoted on bots'
  points alone are back to candidates on upgrade, saying "back to candidate: only review bots raised it (no person)"
  in Studio and in `rigour learn-reviews --list`, for a person to promote again or leave.
- **Candidates only review bots raised are hidden by default.** `rigour learn-reviews --list` and Studio's learning
  page say how many are hidden; `--include-bots` or **Show bot points** lists them. A bot-only lesson taken back or
  back to a candidate stays in view with its reason. `--list --json` still lists every lesson.
- **Write-only-property follows a value carried as another type.** A value put into a property typed as a
  same-shape inline type reaches the serialiser as the type that holds it; its own fields are now hints that name
  that type, not blocks.
- **Write-only-property counts a read through the type a value was carried as.** A field read as `row.p.x`, where
  `p` holds the value under a same-shape type, is read.
- **A test that asserts through a helper is no longer reported as having no assertions.** An imported `expect…`,
  `assert…` or `should…` helper counts, and so does a function, in the test file or an in-repo module it imports,
  whose body asserts. In JavaScript, TypeScript and Python, including a base-class method called on `self`.
- **A check whose only findings the code already had no longer reads FAIL.** In `rigour review --json`, such a check
  reads `PASS` in `checked.checks`, and the new `checked.preexisting` gives the count by check.
