# Rigour 6.9.1

## Fixed

- **The per-edit check no longer flags TypeScript ESM imports.** `rigour hooks check` read `import { b } from './b.js'`
  as a missing file when `b.ts` existed, the way TypeScript's NodeNext and bundler resolution write imports, and with
  `--block` (which `rigour setup` writes) it stopped agents on every edit in such a project. It now resolves imports
  with the same rule as the review: `.js` to `.ts`, `.tsx` or `.d.ts`, `.mjs` to `.mts`, `.cjs` to `.cts`, and a folder
  to its `index`.

## Changed

- **The reviewer's JSON says what a review spent.** `rigour review --reviewer --json` adds `spent_usd`: every run the
  review made, a failed run, a retry, the orchestrator's fallback and cross-examinations included, and 0 for a verdict
  reused from the cache. `cost_usd` stays as it was, the verdict's judges only, so it under-counts a review with a
  failed run and repeats a cached verdict's earlier cost; read `spent_usd` instead. The terminal's cost line shows the
  spent figure too.

## Upgrade

`npm install -g @rigour-labs/cli@latest`. Nothing to migrate.
