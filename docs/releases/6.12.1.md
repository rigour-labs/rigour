# Rigour 6.12.1

The reviewer can run without the GitHub CLI.

## Fixed

- **The reviewer runs without the GitHub CLI.** `rigour review --reviewer --blind` (or `RIGOUR_REVIEWER_BLIND=1`)
  reviews the change alone, with no pull request lookup, description or human reviews, and says so in its output and
  record. Without it, a missing GitHub login still means no verdict, with the reason.
